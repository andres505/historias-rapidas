# historias-rapidas

Homepage + privacy policy for the Google OAuth app "Historias Rápidas e Incorrectas"
(the uploader in `~/projects/social` that posts Shorts to the YouTube channel).
Google requires both URLs to move the OAuth consent screen to **In production**.

Plain HTML, no build. Served by GitHub Pages from `main` /:
- https://andres505.github.io/historias-rapidas/
- https://andres505.github.io/historias-rapidas/privacidad/

Edit, commit, push — Pages redeploys in ~1 min.
