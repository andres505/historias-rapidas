# historias-rapidas

Homepage, privacy policy, terms and data-deletion page for the Google OAuth app + Meta app "Historias Rápidas e Incorrectas"
(the uploader in `~/projects/social` that posts Shorts to the YouTube channel).
Google requires both URLs to move the OAuth consent screen to **In production**.

Plain HTML, no build. Served by GitHub Pages from `main` /:
- https://andres505.github.io/historias-rapidas/
- https://andres505.github.io/historias-rapidas/privacidad/
- https://andres505.github.io/historias-rapidas/terminos/
- https://andres505.github.io/historias-rapidas/eliminacion-de-datos/  (Meta "data deletion instructions")
- https://andres505.github.io/historias-rapidas/icon.png  (1024x1024 app icon for the Meta app)

Edit, commit, push — Pages redeploys in ~1 min.
