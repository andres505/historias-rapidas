Política de privacidad

Última actualización: 20 de noviembre de 2026

Qué es esta aplicación

«Historias Rápidas e Incorrectas» es una herramienta interna que publica videos cortos en el canal de YouTube y en la página de Facebook del mismo nombre, y lee las estadísticas de ambos. La usa únicamente el dueño del canal y de la página, con sus propias cuentas. No se ofrece al público, no tiene inicio de sesión para terceros y no tiene otros usuarios.

Datos de Google (YouTube) a los que accede

Con la autorización del dueño del canal, la aplicación usa la API de YouTube Data y la API de YouTube Analytics para:

  • subir videos al canal del dueño y definir su título, descripción y estado de publicación;
  • leer las estadísticas agregadas del canal y de sus videos (vistas, suscriptores y similares).

Datos de Meta (Facebook) a los que accede

Con un token de la página otorgado por su dueño, la aplicación usa la API Graph de Meta para:

  • publicar videos (Reels) en la página de Facebook «Historias Rápidas e Incorrectas»;
  • leer las estadísticas agregadas de la página y de sus videos (reproducciones, seguidores y similares).

En ambos casos la aplicación no accede a datos personales de espectadores, seguidores ni otras personas, ni a cuentas, canales o páginas que no sean del dueño. Solo usa cifras agregadas.

Cómo se guardan los datos

Los tokens de acceso y las estadísticas se guardan en el servidor privado del dueño, con acceso restringido. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado. Esta aplicación usa los servicios de API de YouTube; consulta también las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. El uso de los datos de Meta se ajusta a las Condiciones de la Plataforma de Meta.

Cómo revocar el acceso y borrar los datos

El acceso de Google se puede retirar en la página de permisos de la cuenta de Google; el de Facebook, en la configuración de la página, sección «Integraciones comerciales». Al revocarlo, el token guardado deja de funcionar de inmediato. Para pedir que se borren los datos guardados, sigue las instrucciones de eliminación de datos.

Contacto
