Política de privacidad

Última actualización: 20 de noviembre de 2026

Qué es esta aplicación

«Historias Rápidas e Incorrectas» es una herramienta interna que publica videos en el canal de YouTube del mismo nombre y lee las estadísticas de ese canal. La usa únicamente el dueño del canal, con su propia cuenta de Google. No se ofrece al público ni tiene otros usuarios.

Datos de Google a los que accede

Con la autorización del dueño del canal, la aplicación usa la API de YouTube Data y la API de YouTube Analytics para:

  • subir videos al canal del dueño y definir su título, descripción y estado de publicación;
  • leer las estadísticas agregadas del canal y de sus videos (vistas, suscriptores y similares) para saber qué contenido funciona mejor.

No accede a datos de espectadores individuales, ni a datos de otras cuentas o canales.

Cómo se guardan los datos

El token de acceso de Google y las estadísticas se guardan en el servidor privado del dueño del canal, con acceso restringido. No se venden, no se comparten con terceros y no se usan con fines publicitarios.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado. Esta aplicación usa los servicios de API de YouTube; consulta también las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de la cuenta de Google. Al revocarlo, el token guardado deja de funcionar de inmediato.

Contacto

Para dudas sobre esta política, escríbenos por mensaje a la página de Facebook de Historias Rápidas e Incorrectas.
